## 聊聊"便宜独立服务器"这件事本身

搜这个词的人大概分三类：

**第一类**，预算真的不多，但业务跑不下去了，VPS 撑不住了。比如跑 MySQL 集群、做大流量爬虫、或者游戏服务器同时在线人数上来了之后 VPS 动不动 OOM 崩掉——这种情况下，找一台便宜独立服务器是最务实的选择。

**第二类**，对资源独占有执念的人。共享主机的"坏邻居效应"（noisy neighbor）真的存在，同一台宿主机上别的租户 IO 跑满，你的服务器就跟着抖。独立服务器物理隔离，CPU 是你的，内存是你的，磁盘 IO 也是你的。

**第三类**，在做测试或者小规模部署，想找个可以任意折腾、root 权限完全掌握在自己手里的机器。

DediRock 的定位基本上覆盖了这三类人：入门款 $59/月（用码后约 $50），配置是 E3-1230v3 + 32GB 内存 + 250GB SSD + 10TB 月流量，在"便宜独立服务器"这个细分里真的算得上有诚意。
